# Edinburgh's map data

Everything the Edinburgh map is built from, as the build reads it, so it rebuilds from a fresh
clone with no downloads. `python3 -I tools/mapdata.py unpack edinburgh` puts it where the build
tools look (`data/raw/edinburgh/wide/`), and the squares and the wide file read `measured/` straight
from here. "Rebuild a map" in the top README has the whole build; `tools/mapdata.py` says how each
part is kept, and `tools/fetch.py` how to fetch it all again (`python3 -I tools/new_area.py build
edinburgh` fetches every source below with no account). Everything was fetched on 11 November 2026.

How the lidar's phase was found: the build doesn't record it, so each kilometre of the lidar box
was read again at low resolution from every survey over it, newest first (the national programme,
then phases 6, 5, 4 and so on, as `fetch.scotland_lidar` reads them), and the survey that filled
it noted. Phase 5 filled all 49, for both the DSM and the DTM, with no gaps left for an older one.
